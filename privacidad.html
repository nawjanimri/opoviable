Información de privacidad

1. Responsable

José Manuel Álvarez Bautista, promotor de OpoViable. Contacto: opoviable@gmail.com.

2. Uso del simulador

Las respuestas introducidas en el simulador se calculan en el navegador del visitante. OpoViable no las envía a Google Sheets, no crea perfiles identificativos de visitantes y no las guarda mediante este formulario en servidores o almacenamiento local del navegador.

3. Consultas y sugerencias por correo

Si decides escribirnos, recibiremos la dirección de correo desde la que envíes el mensaje y el contenido que compartas. Utilizaremos esa información exclusivamente para responder a tu consulta y valorar sugerencias sobre el proyecto. No se utilizará para campañas comerciales ni se incorporará automáticamente a una lista de distribución.

La base jurídica aplicable a la gestión de estas comunicaciones deberá valorarse conforme al contexto concreto (por ejemplo, interés legítimo en atender consultas, cuando proceda). No es necesario facilitar datos personales adicionales para utilizar el simulador.

4. Conservación

Los correos se conservarán durante el tiempo necesario para responder y gestionar la consulta, y posteriormente se eliminarán cuando dejen de ser necesarios, salvo que exista una obligación legal de conservación.

5. Proveedores y alojamiento

La página se publica mediante GitHub Pages, que puede tratar información técnica de conexión como direcciones IP. El correo electrónico se gestiona mediante Gmail (Google), de acuerdo con las condiciones y garantías aplicables de dichos proveedores. Se deben revisar sus condiciones y las posibles transferencias internacionales antes de publicar una versión definitiva.

La presentación de la web utiliza actualmente Tailwind CSS servido desde una red de distribución de contenido externa. Al cargar ese recurso, el navegador puede comunicarse con dicho proveedor. Las fotografías se cargan desde el repositorio de GitHub Pages.

6. Tus derechos

Cuando tratemos datos personales que te conciernan, puedes solicitar el acceso, rectificación, supresión, oposición, limitación o portabilidad, cuando corresponda, mediante un mensaje a opoviable@gmail.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos.

7. Cookies y tecnologías similares

El simulador no instala cookies propias ni utiliza almacenamiento local para guardar las respuestas. Esto no descarta que servicios de terceros asociados al alojamiento o a recursos externos traten información técnica. Antes de la publicación definitiva se revisarán dichos recursos y su comportamiento.
